01
AI Automation / n8n / Workflow Automation

AI-Powered Freelance Opportunity Finder

An automated n8n workflow that searches for new freelance opportunities, processes and normalizes job data, removes duplicates, and uses AI to analyze opportunity relevance. New high and medium-relevance opportunities are stored in Google Sheets and compiled into an automated HTML email report for daily delivery.

Workflow
Schedule → Search Keywords → Freelancer Search → Normalize Data → Remove Duplicates → Check Existing Opportunities → AI Relevance Analysis → Combine Job + Analysis → Keep High & Medium → Save New Opportunities → Generate Email HTML → Send Daily Email → Execution Summary
Key Features
  • Scheduled daily execution
  • Keyword-based opportunity search
  • Freelancer opportunity collection
  • Data normalization
  • Duplicate removal
  • Previously-seen opportunity detection
  • AI relevance analysis
  • High/Medium relevance filtering
  • Google Sheets storage
  • Automated HTML email generation
  • Daily email notification

02
AI Automation / AI Agent / CV Screening

AI-Powered CV Screening & Candidate Analysis

An AI-powered CV screening workflow built with n8n that automatically receives candidate resumes, processes and parses their content, extracts structured candidate information using an LLM, and stores the results in Google Sheets. An AI Agent can then access the candidate data, maintain conversational context, and send information through email, creating an automated candidate screening and management workflow.

CV Processing
CV Form Submission → Upload File → Edit Fields → Download File → LlamaParse → Basic LLM Chain → Structured Output Parser → Google Sheets
AI Agent
Chat Message → AI Agent → OpenAI Chat Model → Simple Memory → Google Sheets Data → Gmail
Key Features

  • File upload processing
  • Document parsing
  • LlamaParse integration
  • LLM-powered CV analysis
  • Structured output
  • Candidate data storage
  • Google Sheets integration
  • AI Agent interaction
